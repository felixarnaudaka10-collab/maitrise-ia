Le guide

L'installer en 3 étapes.

1

Ouvre l'outil

Le projet s'appelle G0DM0D3. Deux options : la version en ligne (rien à installer), ou le fichier à télécharger depuis GitHub et à ouvrir dans ton navigateur.

Version en ligne → Le projet sur GitHub →
2

Branche une clé OpenRouter

Crée un compte sur OpenRouter, ajoute quelques euros de crédit et génère une clé. Colle-la dans Settings → API Keys. Tu paies seulement ce que tu utilises, souvent quelques centimes par question.

openrouter.ai →
100 % gratuit possible : avec des modèles installés sur ton ordi (Ollama), rien ne sort de ta machine et tu ne paies rien. Settings → API Keys → Local Models.
3

Lance le mode Classic

Choisis le mode GODMODE CLASSIC et tape ta question. Plusieurs IA répondent en même temps et tu vois en direct laquelle te donne la meilleure réponse.

Écris 3 slogans pour [mon activité] à [ma ville],
pour des clients qui cherchent [ce qu'ils veulent].
Explique pourquoi chacun fonctionne.
!

À savoir avant de l'utiliser

  • Tes questions sont envoyées au service que tu branches (OpenRouter par exemple). Seuls les modèles locaux restent sur ton ordi.
  • L'outil envoie des statistiques d'usage anonymes par défaut. Tu peux les couper avec le mode local.
  • C'est un outil de recherche : sers-t'en pour comparer les IA, pas pour contourner leurs règles.
