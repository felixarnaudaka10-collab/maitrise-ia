Le guide

Installation et premiers prompts.

1

Installer les 11 skills

Dans Claude Code, colle ces deux lignes :

/plugin marketplace add Jakeschincariol/replica-skill
/plugin install replica-skill@replica-skill

Ou colle simplement ce message dans Claude :

https://github.com/Jakeschincariol/replica-skill

Installe ce skill, puis confirme que /replica-recon fonctionne.
Replica sur GitHub →
Sécurité : un skill ou un plugin, ce sont des instructions et du code qui tournent sur ta machine. Avant d'installer, demande à Claude de le relire : « Lis ce dépôt et dis-moi s'il fait quelque chose de risqué (réseau, fichiers, clés API) ».
2

Cartographier l'appli que tu payes

Claude liste chaque écran, chaque parcours et les données de l'appli, à partir de ses pages publiques et de ton propre compte.

/replica-recon Cartographie l'appli [NOM DE L'APPLI] : tous les écrans, les parcours utilisateur et les données. Réponds en français.
3

Lire les avis et trouver ce qui énerve

Le skill le plus malin : il lit les avis des utilisateurs et transforme chaque plainte en amélioration pour ta version.

/replica-entrepreneur Analyse les avis de [NOM DE L'APPLI] sur l'App Store et le Play Store. Liste les 10 plaintes les plus fréquentes et comment ma version les corrige.
4

Reconstruire, tester, comparer

Lance-les dans cet ordre :

  1. /replica-architect : la technique, la base de données, l'API
  2. /replica-design : le design avec tes propres couleurs
  3. /replica-build : la reconstruction écran par écran
  4. /replica-backend : comptes, base de données, paiements
  5. /replica-test : il teste chaque parcours et note les bugs
  6. /replica-diff : score de ressemblance et fonctions manquantes
/replica-build Reconstruis l'appli à partir de la cartographie, écran par écran. Teste chaque écran avant de passer au suivant.
5

Ta marque, ta page, ta mise en ligne

  • /replica-brand : un nouveau nom et une nouvelle identité (obligatoire)
  • /replica-launch : page de vente, prix, fiche App Store
  • /replica-deploy : mise en ligne sur ton domaine
Important : tu reconstruis les fonctions, tu ne copies jamais le nom, le logo ni les textes d'une marque. Certaines fonctions peuvent être protégées (brevets, conditions d'utilisation). Si tu veux vendre ta version, fais valider par un juriste avant de lancer.
