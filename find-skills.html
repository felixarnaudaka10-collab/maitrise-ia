Le guide

Installation et premiers prompts.

1

Installer Find Skills

Dans ton Terminal :

npx skills add vercel-labs/skills --skill find-skills

Ou colle ce message dans Claude Code :

Installe le skill find-skills de vercel-labs/skills (npx skills add vercel-labs/skills), puis confirme qu'il fonctionne.
Le classement skills.sh →
2

Lui demander le bon skill

Décris ce que tu fais, il cherche, compare et installe :

Trouve-moi le meilleur skill pour [monter mes vidéos / écrire mes emails / faire mes devis]. Compare les 3 premiers et installe le plus fiable.
3

Toujours vérifier avant d'installer

N'importe qui peut publier un skill. Avant d'en garder un, fais-le relire :

Relis le skill [NOM] que tu viens d'installer : liste tout ce qu'il fait sur ma machine (fichiers, réseau, commandes, clés API) et dis-moi s'il y a un risque. Si oui, désinstalle-le.
Sécurité : un skill ou un plugin, ce sont des instructions et du code qui tournent sur ta machine. Avant d'installer, demande à Claude de le relire : « Lis ce dépôt et dis-moi s'il fait quelque chose de risqué (réseau, fichiers, clés API) ».
