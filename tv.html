Étape 1

Prépare ta TV.

1

Active le mode développeur

Sur la TV : Paramètres → Préférences de l'appareil → À propos → appuie 7 fois sur OK sur « Build ». Reviens en arrière → Options pour les développeurs → active le débogage USB (et le débogage réseau / ADB si ta TV l'affiche).

Étape 2

Le prompt à coller dans Claude Code.

2

Récupère le projet

git clone https://github.com/Gathin23/cleanyourtv
cd cleanyourtv

Ouvre ce dossier dans Claude Code.

Le projet sur GitHub →
3

Colle le prompt (remplace le modèle)

I want to debloat my Android TV and replace its launcher with a clean Apple TV style home screen.
My TV model is: [LE MODÈLE DE TA TV, ex : Xiaomi Mi TV 4A]. Work on the real device, step by step, and verify everything you do with screenshots pulled from the TV. Ask me before anything that depends on my preferences.
Follow PROMPT.md in this repo for the full procedure.

Claude trouve la TV sur ton Wi-Fi, te demande quelles applis garder, désactive le reste (pubs, trackers, applis inutiles) et installe le nouvel écran d'accueil.

Le prompt complet (PROMPT.md) →
Étape 3

Tu veux revenir en arrière ?

4

Une seule commande

TV_HOST=<ip de ta tv> tools/restore.sh examples/<ton-modèle>/debloat.txt

Rien n'est désinstallé (tout est seulement désactivé) : la TV revient exactement comme avant.
