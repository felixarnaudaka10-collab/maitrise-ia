Les 5 skills.

1

Marketing Skills

par Corey Haines
Installe une vingtaine d'agents marketing d'un coup : audit SEO, copywriting, séquences email, CRO, analytics, stratégie de contenu. Ensuite tu appelles /seo-audit, /email-sequence, /performance-report…
/plugin marketplace add coreyhaines31/marketingskills /plugin install marketing-skills
github.com/coreyhaines31/marketingskills →
2

Stop Slop

par Hardik Pandya
Force Claude à humaniser ton écriture. Il vire les tirets cadratins, les « il est important de noter que », le jargon et toutes les tournures qui sentent l'IA à dix kilomètres.
/plugin marketplace add hardikpandya/stop-slop /plugin install stop-slop
github.com/hardikpandya/stop-slop →
3

UI UX Pro Max

par Next Level Builder
Donne à Claude une base de plus de 50 styles d'interface et des dizaines de règles UX (couleurs, typo, charts, accessibilité). Résultat : des designs qui ressemblent enfin à du travail de pro, pas à du template IA.
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill /plugin install ui-ux-pro-max@ui-ux-pro-max-skill
github.com/nextlevelbuilder/ui-ux-pro-max-skill →
4

Remotion

plugin officiel Remotion
Permet à Claude de générer des vidéos entièrement animées, en code. Animations, transitions, sous-titres, graphiques animés. C'est le skill qui monte des vidéos comme celle que tu viens de voir.
claude plugin marketplace add remotion-dev/claude-code-plugin claude plugin install remotion@remotion
remotion.dev — doc officielle →
5

Context Engineering Kit

par NeoLab
Réduit le nombre de tokens que Claude consomme par réponse : compaction, compression, gestion de la mémoire. Traduction concrète : tu tapes beaucoup moins vite dans tes limites d'usage, et Claude reste précis plus longtemps.
/plugin marketplace add NeoLabHQ/context-engineering-kit
github.com/NeoLabHQ/context-engineering-kit →
