Le guide

Installation et premiers prompts.

1

Mettre Claude Code à jour

Dans ton Terminal, vérifie ta version :

claude --version

Si elle est plus ancienne que 2.1.287, mets à jour :

claude update
2

Mod 1 : « You should know » (déjà intégré)

Une deuxième IA relit la conversation pendant que Claude travaille et t'affiche une note quand elle repère quelque chose que tu as pu rater : un choix fait sans te prévenir, un résultat bizarre. Elle n'a aucun outil, elle ne peut rien modifier.

Dans Claude Code, tape :

/plugin enable cc-plugin-you-should-know@builtin
À savoir : chaque vérification consomme un peu de ton forfait. Pour l'éteindre : /plugin puis désactive-le.
3

Mod 2 : le relais avant compression

Sur une longue session, la mémoire de Claude se remplit et il se compresse. C'est là que des infos importantes disparaissent. Ce mod se déclenche juste avant, écrit un résumé (ce qui est fait, les décisions, la suite) et te permet de repartir dans une session neuve exactement où tu t'étais arrêté.

Claude Code sait écrire ses propres mods. Colle ce message :

Crée-moi un mod Claude Code appelé "relais" : quand le contexte dépasse 80 %, écris un fichier RELAIS.md avec ce qui est fait, les décisions prises, les fichiers modifiés et les prochaines étapes, puis affiche une note pour me proposer d'ouvrir une nouvelle session qui commence par lire RELAIS.md. Montre-moi le code avant de l'installer.
La doc officielle des mods →
Sécurité : un skill ou un plugin, ce sont des instructions et du code qui tournent sur ta machine. Avant d'installer, demande à Claude de le relire : « Lis ce dépôt et dis-moi s'il fait quelque chose de risqué (réseau, fichiers, clés API) ».
4

Bonus : 3 mods d'exemple d'Anthropic

  • token-weather : une météo de ta mémoire au-dessus du champ de saisie
  • blast-radius : bloque une commande risquée (suppression, force push) et te montre ce qu'elle changerait
  • replay-theater : rejoue les modifications de fichiers du dernier tour
