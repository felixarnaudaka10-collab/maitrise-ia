Le guide

Installer et scanner en 3 étapes.

1

Installer SkillSpector

Dans le Terminal (il faut uv) :

uv tool install git+https://github.com/NVIDIA/skillspector.git
SkillSpector sur GitHub →Guide officiel NVIDIA →
2

Scanner tes skills

# Scanner un skill avant de l'installer
skillspector scan ./mon-skill/

# Scanner un seul fichier SKILL.md
skillspector scan ./SKILL.md

# Scanner un skill hébergé sur GitHub
skillspector scan https://github.com/auteur/le-skill

# Scanner tous tes skills déjà installés
skillspector scan ~/.claude/skills/ --no-llm
3

Le réflexe automatique dans Claude

Colle cette instruction dans ton CLAUDE.md :

Avant d'installer un nouveau skill, lance toujours : skillspector scan <chemin ou lien du skill> --no-llm. Montre-moi le score de risque et ce qui a été trouvé. Si le score dépasse 30 ou si une commande réseau, une lecture de mots de passe ou un envoi de données apparaît, n'installe rien et demande-moi d'abord.
Important : un score faible réduit le risque, il ne le supprime pas. Installe uniquement des skills de sources que tu connais.
