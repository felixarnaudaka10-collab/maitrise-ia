La méthode

Étape par étape.

1

Claude + un agent qui travaille sur tes fichiers

Deux options : Claude Code (dans le terminal) ou Cowork dans l'app Claude pour ordinateur (c'est ce que j'utilise : je dépose mes rushs dans un dossier, Claude me rend le montage). Il faut un abonnement payant Claude.

Installer Claude Code (Mac / Linux) :

curl -fsSL https://claude.ai/install.sh | bash
Documentation Claude Code →
2

Installe HyperFrames

HyperFrames transforme du HTML animé en vraie vidéo MP4. Open source (licence Apache 2.0), sans frais par rendu, créé par HeyGen. Il te faut Node.js 22+ et FFmpeg (sur Mac : brew install ffmpeg).

Dans Claude Code :

claude plugin marketplace add heygen-com/hyperframes
claude plugin install hyperframes@hyperframes

Ou pour n'importe quel agent :

npx skills add heygen-com/hyperframes
HyperFrames sur GitHub →
Pourquoi pas Remotion ? Remotion est très bien aussi, mais sa licence gratuite est réservée aux structures de 3 personnes maximum. HyperFrames est gratuit sans condition.
3

Tourne tes vidéos en batch

  • Téléphone à la verticale, mode Normal (pas HDR), micro-cravate si possible.
  • Refais tes phrases autant que tu veux : Claude garde la meilleure prise.
  • Dépose tous tes rushs dans un seul dossier.
4

Demande le montage

Dans ce dossier, j'ai mes rushs vidéo (face caméra, format vertical). Monte-moi un Reel Instagram de 30 à 60 s avec HyperFrames :
1. Transcris l'audio mot à mot (Whisper), garde la meilleure prise quand je me répète, coupe les silences de plus de 0,35 s, les faux départs et les hésitations.
2. Écran scindé : en haut, des animations qui illustrent ce que je dis (cartes, logos réels des marques citées, compteurs animés) ; en bas, ma face caméra, tête en haut du cadre.
3. Sous-titres mot à mot en MAJUSCULES, texte noir sur fond jaune, calés sur ma voix.
4. Effets sonores : pop à chaque apparition, whoosh à chaque changement de scène, clavier quand du texte s'écrit. Musique de fond très basse. Voix normalisée à -14 LUFS.
5. Rendu MP4 1080x1920, puis montre-moi 6 images clés avant de me livrer la vidéo.
5

Fais-lui retenir ton style

Garde en mémoire ma charte de montage (couleurs, police, style des sous-titres, cadrage, effets sonores) dans un fichier CHARTE-MONTAGE.md, et applique-la automatiquement à chaque nouveau Reel que je dépose dans ce dossier.
Mon astuce : à chaque retour (« tête trop zoomée », « plus d'effets sonores »), dis-lui de mettre à jour la charte. Au bout de 3 vidéos, le montage sort quasiment parfait du premier coup.
