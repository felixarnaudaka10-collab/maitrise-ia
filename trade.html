Le guide

Installation et premiers prompts.

1

Installer le Trader skill

Colle ce message dans Claude :

https://github.com/Jakeschincariol/day-trader-skill
install skill

Dans Claude Code, tu peux aussi l'installer comme plugin :

/plugin marketplace add Jakeschincariol/day-trader-skill
/plugin install day-trader-skill@day-trader-skill
Le dépôt GitHub →
2

Scanner le marché

Le scanner passe des milliers de graphiques en revue et te sort les setups :

Utilise le Trader skill : scanne les actions US et sors-moi les 5 meilleurs setups du jour, avec pour chacun la raison en une phrase.
3

Planifier un trade

Entrée, stop et objectif posés avant d'entrer :

Planifie un trade sur TSLA : point d'entrée, stop et objectif. Vérifie-le avec le skill risque et les actus du jour avant de me le proposer.
4

Le tester avec la Time Machine

Elle rejoue le reste de la séance 10 000 fois à partir de l'historique de l'action, et te donne les vraies probabilités :

Passe ce trade dans la Time Machine. Dis-moi en pourcentage combien de fois j'atteins mon objectif d'abord, combien de fois mon stop d'abord, et combien de fois je finis entre les deux. Explique-moi simplement si ça vaut le coup.
Important : reste en paper trading tant que tu n'as pas compris ce que tu fais. Le skill te montre des probabilités passées, pas l'avenir. Ce guide n'est pas un conseil financier : le trading peut faire perdre de l'argent.
5

Toujours vérifier avant d'installer

N'importe qui peut publier un skill. Fais-le relire :

Relis le Trader skill que tu viens d'installer : liste tout ce qu'il fait sur ma machine (fichiers, réseau, commandes, clés API, accès à un courtier) et dis-moi s'il y a un risque.
