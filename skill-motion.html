Étape 2

Installe-le en un prompt.

2

Dans l'application Claude (le plus simple)

Ouvre un nouveau chat, glisse le zip dedans, puis colle :

Voici le skill motion-video-director (fichier joint).
1. Installe-le : enregistre son SKILL.md et ses fichiers comme skill, pour que je le retrouve dans mes prochaines conversations. Dis-moi quand c'est fait.
2. Vérifie que tu as tout ce qu'il faut pour l'utiliser (ffmpeg, Node, le connecteur ElevenLabs pour la voix) et dis-moi ce qui manque, en une phrase par élément.

Claude te montre une carte : clique sur Enregistrer.

3

Avec Claude Code

Décompresse le zip dans ~/.claude/skills/ (Mac) puis relance Claude Code. Il te faut aussi ffmpeg : brew install ffmpeg sur Mac, winget install ffmpeg sur Windows.

Étape 3

Ta première vidéo.

4

Colle ce prompt (remplace ce qui est entre crochets)

Avec le skill motion-video-director, fabrique-moi un Reel vertical de 30 secondes, de A à Z.
Sujet : [ton sujet]
Pour qui : [ta cible]
Mot-clé en commentaire : [MOT]
- Écris le script et découpe-le en scènes (une idée par scène, 5 mots max à l'écran).
- Propose-moi deux voix françaises ElevenLabs avec le coût estimé, et ATTENDS mon feu vert.
- Génère la voix (meilleur modèle, une seule prise), puis cale chaque animation sur le mot prononcé.
- Ajoute un bruitage par animation et une musique très basse sous la voix.
- Montre-moi la planche de contrôle, puis rends le MP4 1080×1920.
5

Refaire un Reel qui t'a plu

Voici un Reel dont j'adore le style (vidéo jointe). Avec le skill motion-video-director, refais-le en français scène par scène, sur mon sujet : [ton sujet]. Même rythme, mêmes animations, mêmes couleurs. Ne reprends jamais les chiffres de l'autre créateur. Montre-moi le découpage avant de générer la voix.
Les règles

Pour un rendu pro.
