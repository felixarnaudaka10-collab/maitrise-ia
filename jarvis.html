Le guide

Étape par étape.

1

Donne-lui un corps

Ton Jarvis a besoin d'une machine allumée pour tourner. Trois options :

  • Un vieux PC portable : gratuit si tu en as un qui dort dans un placard.
  • Un Mac mini : silencieux, consomme peu, parfait pour tourner 24h/24.
  • Un serveur en ligne (VPS) : quelques euros par mois, toujours allumé, accessible de partout. C'est l'option la plus efficace.
Pour démarrer ce week-end, ton ordinateur actuel suffit. Tu passeras sur un Mac mini ou un VPS quand tu voudras qu'il tourne en continu.
2

Choisis son cerveau

Le cerveau, c'est le modèle d'IA (LLM). Claude, ChatGPT ou Gemini peuvent faire l'affaire. Ce guide utilise Claude, parce qu'il a son propre moteur d'agent (étape 3).

Il te faut un abonnement Claude Pro ou Max, ou un compte développeur Anthropic. Le plan gratuit ne donne pas accès à Claude Code.

3

Installe le moteur : Claude Code

Claude Code transforme un simple chat en agent qui agit tout seul : il lit et écrit des fichiers, lance des commandes, utilise tes outils. Ouvre le Terminal et colle :

curl -fsSL https://claude.ai/install.sh | bash

Sur Windows (PowerShell) :

irm https://claude.ai/install.ps1 | iex

Ensuite, crée un dossier jarvis, ouvre un terminal dedans et tape claude. Connecte-toi avec ton compte Claude. C'est parti.

Documentation officielle →
4

Apprends-lui qui tu es

Claude Code lit automatiquement un fichier CLAUDE.md dans ton dossier à chaque session. C'est la « fiche d'identité » de ton Jarvis. Colle ce prompt dans Claude Code :

Tu es mon assistant personnel, mon Jarvis. Pose-moi une
par une les questions nécessaires pour bien me connaître :
mon métier, mon business, mes clients, mes offres et mes
prix, ma façon de travailler, mes process récurrents, mon
ton d'écriture et mes priorités du moment.
Quand tu as tout, rédige un fichier CLAUDE.md clair et
structuré dans ce dossier, que tu reliras au début de
chaque session.
5

Branche-le à tes outils

Ta boîte mail, ton agenda, ton navigateur, tes logiciels : on les connecte avec des serveurs MCP (le standard ouvert pour relier une IA à tes applications) ou avec des clés API.

  • Dans l'app Claude : Réglages → Connecteurs pour Gmail, Google Agenda, Drive, Notion…
  • Dans Claude Code : la commande claude mcp add pour ajouter un serveur MCP.
Je veux que tu puisses gérer mes mails, mon agenda et
naviguer sur le web pour moi. Liste-moi les serveurs MCP
ou connecteurs officiels à installer pour ça, explique-moi
à quoi sert chacun, puis installe-les un par un avec moi
en me demandant les autorisations nécessaires.
Ouvrir mes connecteurs Claude →
6

Une mémoire permanente et des skills

La mémoire : ton CLAUDE.md sert déjà de mémoire de base. Pour aller plus loin, des outils comme Letta donnent à un agent une mémoire longue durée.

Les skills : ce sont des fiches d'instructions pour tes tâches répétitives (relancer un client, préparer un devis, trier tes mails). Dans Claude Code, chaque skill vit dans un dossier .claude/skills/nom-du-skill/SKILL.md.

Regarde mon CLAUDE.md et identifie les 3 tâches que je
fais le plus souvent. Pour chacune, crée un skill dans
.claude/skills/ avec un fichier SKILL.md qui décrit
précisément quand l'utiliser et comment la réaliser étape
par étape, dans mon style. Ensuite, teste le premier skill
avec moi.
Le mot magique : à chaque fois qu'il fait un truc bien, dis-lui « garde ça en mémoire ». Il l'écrit dans son CLAUDE.md et ne l'oublie plus.
7

Une voix et une interface

La voix : crée un compte ElevenLabs, choisis une voix (ou clone la tienne), récupère ta clé API et demande à Claude Code de la brancher.

L'interface : avec Claude Design (inclus dans Claude Pro, Max, Team et Enterprise), tu décris l'interface de ton Jarvis et Claude la dessine. Tu la connectes ensuite à la voix.

Voici ma clé API ElevenLabs : [COLLE TA CLÉ].
Branche-la pour que tu puisses me répondre à voix haute
avec la voix [NOM DE LA VOIX]. Ensuite, crée-moi une
petite interface web façon assistant futuriste : un bouton
micro pour te parler, ta réponse écrite et lue à voix
haute. Explique-moi comment la lancer.
ElevenLabs → Claude Design →
Sécurité : ne colle jamais une clé API dans un fichier partagé ou sur GitHub. Garde-la dans un fichier .env et demande à Claude de l'utiliser depuis là.
