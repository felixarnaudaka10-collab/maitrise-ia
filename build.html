Le dépôt

C'est quoi, Build Your Own X ?

Une liste géante de tutoriels gratuits pour recréer toi-même les technologies que tu utilises tous les jours : Git, Docker, une base de données, un navigateur, un système d'exploitation, un langage de programmation… Chaque guide part de zéro et avance pas à pas, dans le langage de ton choix.

Le bonus

Claude comme prof particulier.

1

Apprendre sans copier-coller

Le piège, c'est de laisser l'IA coder à ta place : tu n'apprends rien et tu ne sauras pas l'expliquer. Ce prompt fait de Claude un prof qui te guide sans te donner la réponse.

Tu es mon prof de programmation. Je veux construire [mon propre Git] à partir de zéro, en [Python], en suivant ce guide : [colle le lien du tutoriel choisi dans build-your-own-x].
Règles :
- Ne m'écris PAS le code à ma place. Explique-moi chaque étape, donne-moi un indice, et laisse-moi coder.
- Quand je bloque, pose-moi une question qui m'aide à trouver moi-même.
- Après chaque étape, vérifie mon code et explique-moi ce qui se passe « sous le capot ».
- Commence par me dire en 5 lignes comment [Git] fonctionne vraiment.
2

Le transformer en atout sur ton CV

Une fois le projet terminé, prépare-toi à en parler en entretien.

Je viens de construire [mon propre Git] à partir de zéro. Voici mon code : [colle ton code ou le lien GitHub].
1. Écris la ligne de mon CV pour ce projet (une phrase, avec ce que j'ai appris).
2. Écris un README clair pour mon dépôt GitHub.
3. Pose-moi 5 questions qu'un recruteur technique me poserait en entretien sur ce projet, puis corrige mes réponses une par une.
